# 阈值轨迹回放与受控分叉诊断

## 结论与证据边界

全部有限实验与交付验收已完成。人工解释与同目录机器汇总相互对应；未修改原入口5,168条详细轨迹全部一致，64状态数值复核及完整成本已核清，delivery_verification.json状态passed。全部数据是反复使用的开发诊断人口，不是独立测试集。

**A：139/L5 首轮 return 的放行决定了长短路径。** r0 s1候选仍是 ` return`，原概率.933616被头改为.963579，跨过.95。固定候选仅改当前评分，完整总前向63→3、扩展59→0，八个延续种子均通过、最终词元相同。其余三次事实头调用单次取消均无生成效果。从完整相同的无头快照只加这一次头、未来继续无头，也得到相同60次节省；首次扩展前最后一个合格状态再加头则无效。这超过“最早差异”的相关性证据。早期放行改变普通前缀、次轮选位/链、EOS抵达和后续短画布扩展；每个中介的独立必要性没有逐一识别。

**B：在可识别的受控样本中，作用来自同词放行，改词效应与交互没有识别。** 全量13,752次头调用中13,495次候选不变（98.13%）；固定64面板及16专项状态的当前候选全部相同，故QP/PP与QQ/PQ在生成和质量上相同，四组交互为0是因子未激活的机械结果。面板PQ−PP平均余NFE−.140625，无质量或最终词元变化。不能把这个0解释成全局无候选效应：自然路径有257次改候选，其中3次普通接受、179次普通拒绝、75次头结构刷新。它们没有在预定面板得到受控识别，不能追补挑选样本。升分亦不必有益：6/L0、32/L4放行可改错；105/L16降分拒绝反而稳定救回，头不是统一置信度提升器。

**C：同链传播和结构时机确有局部因果作用，但不存在统一的“少结构即好”。** 139 .95取消一次拒绝传播或延后/否决首次删除，都从63→4、消除59次扩展且保留答案；只延后首次扩展却多一轮，否决该次扩展才变4轮。126两阈值延后/否决首次删除，0/8通过→8/8，通过代价是多4—8次前向，双方仍扩展64次；压首次扩展未救回。80两阈值延后/否决首次删除，虽省21/23次余前向，却8/8通过→0/8；压首次扩展也有损害。顺序/豁免位置2×2的预定触发条件在六条焦点路径全不存在，六条N/A保留，不能给出两因素的独立效果。

**D：139的首调用效应跨八种子稳定；并非所有质量翻转稳定。** 105/L16、37/L2单次效应在八延续中稳定救回；114/L4、32/L4、99/L7会反向，6/L0的更低成本包括质量损失。部分完整历史翻转在取消首次差异调用后仍通过，说明单次首差异不足以解释完整策略，可能有后续补偿/冗余。另54条seed43—45从头生成中，139与80的六配置输出、NFE、扩展和通过完全保持历史结果；126 K4无头失败、有头.95通过的方向也保持，但无头错误路径和NFE变化。三病例不能估计总体稳定率。

**E：最支持先做“固定候选的条件评分/概率校准对照”，并把结构时机作为紧随的机制研究；不足以直接支持扩大全词表依赖头训练。** 现有控制直接定位到评分跨阈值；教师接近fresh是依赖修正的正证据，却不等于校准或代码正确。应比较有条件的升降分、廉价评分修正和旧头，而不是只做统一锐化。结构研究有强干预证据，但80的质量反例反对直接部署统一延后/否决规则。完整支持/反对表见下文。本轮没有启动训练、校准新实验、阈值搜索或新策略矩阵。
