# H2为什么距离K1仍较远

全部使用A/H2已归档的1033行同协议结果，不重跑基线。

|方法|通过/N|通过率|
|---|---:|---:|
|K4零头|820/1033|79.38%|
|K4冻结旧静态头|842/1033|81.51%|
|H2|851/1033|82.38%|
|K4真实当前链fresh重算（F4-chain）|912/1033|88.29%|
|K1每步模型重算/重新选位|949/1033|91.87%|

H2相对零头救回56、改错25，净增31（+3.00个百分点，164基础题分组95%区间[1.15,4.88]）。相对旧头救回38、改错29，净增9（+0.87个百分点，区间[-0.76,2.48]），尚不能确认优于旧静态头。

H2相对真实当前链fresh重算救回10、改错71，净少61（-5.91个百分点，区间[-8.22,-3.80]）。真实fresh本身又比K1净少37行。因此851→912→949能在数值上描述缺口，但不是因果分解；各方法会产生不同的生成轨迹。

训练并非没有学习信号：完整验证KL从0.29015降到0.11201（约61.4%）；T=.2/top_p=.9固定随机输入的teacher采样不一致率从7.63%降到4.585%。这是验证库上的分布/采样指标，不等于闭环生成的程序通过率。H2第4轮best，第5轮KL回升，不能仅据此建议自动增加轮数。

代码可直接确认的范围限制：K4先固定一批选位并按左到右提交；H2只能改已有合法同链历史的后续普通词分布，首词、跨链及结构处理继续沿用A。K1则每轮模型重算后重新选1个位置。即使逐状态完全逼近同链teacher，也不保证走出与K1相同的轨迹。

另一个可确认的差异是训练状态来自Z4和冻结旧头轨迹，评测时来自H2自身生成轨迹。它可能影响泛化，但当前没有受控实验量化其影响，不能据此认定为主要原因。参数容量、分布偏移、局部误差累积的具体贡献仍待诊断；不自动加训或扩展实验。

正式结论应是：相对零头有收益，优于旧静态头的证据不足，离fresh参考和K1均有明显差距。缺少同数据Hctx和必要消融，不能声称多词记忆的因果优势。
