# CPU重放与影响证明方法

对全部37722逻辑行读取原始离散提交和实际输入分词，重建固定prefix、初始64MASK、suffix及2048最大宽度。重放原赋值、EOS广播、降序扩展与截断、旧删除坐标、填充MASK以及长度/预算更新。每轮核验旧扩删计数；历史记录还逐轮核验活动mask位置、画布长度和残mask。每行最终全部生成token IDs、动态长度、prefix/suffix、NFE均吻合封存结果。

旧复用frontier记录只有top4草稿，某些已提交普通词不在top4。先用唯一符号跟踪这些普通词的持久坐标；普通提交以后不会被mask删除资格覆盖。其最终保留坐标给出已封存final token ID约束（不使用decoded字符串或passed），验证均为普通词元，再重放一次。这是恢复既有普通提交值的CPU约束，不是模型重新预测，恢复数量每行记在reconstructed_ordinary_tokens。旧未提交草稿不重建；其值对后续画布无作用。

随后在每轮共同旧状态上分别执行旧/修正结构变换，首次完整x或长度不同即记录窗口、旧/新删除资格坐标并停止反事实重放；仍用旧语义验证封存轨迹余下部分。首次分歧后的旧草稿不用于修正通过率或新输出。若无法验证旧语义则标unknown并纳入补跑；本次unknown0。

37596行每轮整条x/长度相等，修改不消费RNG，不改变普通词、头、选位/广播/预算或结构屏障，故确定性归纳给出完整生成/评分复用。126行首分歧需实际大模型重生成；37单行、28/28/33多行与EOS残留线索数量恰好相同只是重放结果，筛选未读passed或最终EOS计数。多行配对并集38ID其它臂有各自等价证明。

修正只把扩展前的EOS删除资格随插入移动：被替换expand位置变两个false资格，之后一起截断；仍以降序执行正确新位置的删除，保留官方EOS广播。新增mask、固定上下文和已提交普通词不会因此成为可删EOS。K1/链K4/frontier/Base的非干扰同时由实际全行重放和CPU原生参考回归支持。
