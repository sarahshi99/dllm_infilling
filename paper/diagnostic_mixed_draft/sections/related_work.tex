\section{Related Work}
CAL provides training-free calibrated adaptive length with official HumanEval-Infilling preprocessing and model-specific implementations. rho-EOS uses implicit EOS density for single-stage bidirectional length adjustment, while DreamOn is a training-based dynamic-canvas code-infilling method. LR-DLLM proposes training-free length regularization but currently lacks an executable adapter in our repository. These methods make dynamic length itself insufficient as a novelty claim; comparisons must separate training-based and inference-only strata and match model, prompt, data, evaluator, decoding budget, and compute.
